## 本轮发现并修复

- 3D 初始灯光过曝、角色过小：调整曝光与正交构图，添加接触阴影。
- 家具杆件误用世界坐标朝向，导致桌腿、衣架和部分装饰倾斜：改用父节点局部方向的四元数，并验证端点位置。
- 不必要的高分段基础几何：降低球体／胶囊／圆柱分段。
- 长裤腰部露出基础衣、长袖肩部不足：增加裤腰连接网格与袖子覆盖长度。
- 320 宽舞台按钮溢出、竖屏人物按钮与工具条重叠：缩小紧凑布局并适配短视口。
- 手机衣橱卡片被下方色板遮住：改为横向单排大卡片；较高视口采用网格。
- 横屏设置面板溢出：限制面板高度并允许滚动。
- 快速连续点按动作造成节点或动作叠加：原生场景交互节流并限制短时效果节点。
- 离开衣橱去原有小镇时，隐藏的 3D 场景仍可能播放：路由离开时暂停，返回恢复；音乐按同一生命周期管理。
- 原有小镇缺少桌面端明确返回入口：新增返回衣橱按钮，并覆盖 320 宽小屏导航测试。
- 普通 iOS 构建引用未导出的 Unity 符号：本地可选编译适配；恢复模拟器目标及 Debug 模式。

## 尚未验证的发布条件

没有进行真实 iPhone／iPad 的长时间持续 FPS、发热、电量、内存峰值、低端机与中断恢复实测。`preferredFramesPerSecond = 60` 是目标设置，不是已测得的性能结果。

未组织目标年龄儿童试玩，不能据此声称孩子一定能独立完成全部操作。需要观察点击命中、衣橱横向浏览、拖动与转身的理解、拍照面板退出，以及重复游玩的兴趣。

iOS 真机 Release 产物未签名，尚未上传 TestFlight／App Store；Mac 本地 Release 包没有完成面向外部分发的 Developer ID 公证。未将这些发行工作标记为完成。

语音使用设备系统中文音色，尚未制作专业录音配音。美术是原创程序化玩具风格，未声称达到外包雕刻、真实布料模拟或影视级角色标准。
