# 怪兽星球 3D（Unity 原型）

这是 ColorHug 旁边的独立 Unity 3D 战斗原型，不会改动或替换现有 Flutter 游戏。第一阶段目标是验证孩子是否喜欢“亲自操作光之战士战斗”的核心体验。

## 已包含的玩法骨架

- 第三人称自由移动、镜头跟随、跳跃和带无敌帧的闪避
- 三段近战连击、能量冲击波和蓄能光线技能
- 怪兽追击、侧移、攻击预警、受击硬直和倒地
- 三位原创光之战士可选，各自有不同速度、力量和能量特性，并使用真正的蒙皮模型和动作片段
- 手机左侧虚拟摇杆，右侧攻击、闪避、跳跃、技能按钮
- 普通话语音引导：选角色、开战、闪避提醒、能量满、胜利和重试
- 命中特效、冲击波、残影、镜头震动、慢动作和程序化战斗音效
- 编辑器内键鼠调试：`WASD` 移动，`Space` 跳跃，`J` 攻击，`K` 闪避，`L` 技能

## 打开与生成场景

1. 用 Unity Hub 打开本目录，编辑器版本选择 **Unity 6.3 LTS (6000.3.22f1)**。
2. 首次打开等待 Package Manager 完成依赖解析。
3. 点击菜单 **Monster Planet > Build Playable Prototype**。
4. 打开 `Assets/Scenes/MonsterPlanetPrototype.unity`，点击 Play。

场景由编辑器脚本生成，不需要手工拖拽几十个引用。后续导入正式的蒙皮角色和动作后，可以继续沿用同一套移动、战斗和 AI 代码。

## 移动端建议

- 先用 60 FPS、中等分辨率、单只主怪兽验证手感。
- 正式模型尽量控制在每个角色 2–4 万三角面，纹理以 1K 为主。
- iPhone 构建放到 `Builds/iOS`；不要把 Unity 的 `Library`、`Build` 等缓存提交到 Git。

## 素材原则

原型内置 3 位可选角色和 1 只怪兽的蒙皮动画模型，并保留程序化模型作为素材导入失败时的兜底。素材来自 Quaternius 的免费模型包，使用 **CC0 1.0**，许可文件见 `Assets/ThirdParty/Quaternius/License.txt`。这几份经过挑选的自包含 glTF 文件合计约 5.6 MB，没有把整套素材包和 Unity 缓存塞进仓库。

这些模型用于验证玩法和动画手感，不包含任何影视截图或未经授权的奥特曼模型。正式美术阶段可替换为自己制作或获得授权的 FBX/GLB 蒙皮角色，而移动、战斗、AI 和手机操作代码不需要重写。
