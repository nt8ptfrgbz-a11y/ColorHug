# Silly Town original audio

All 14 WAV files are original procedural sound design created for this project
by `tool/generate_town_audio.py`. No downloaded samples, external music or cloned
voices are used. Files are stereo 16-bit PCM at 22050 Hz. Music: 88 BPM, eight-bar
loop with marimba melody, plucked accompaniment and soft bass. The loop includes
wrapped release tails. Effects have attack/release envelopes and capped peaks.

English narration is separate, produced at runtime by the device's installed
English TTS voice. It is not embedded in these WAV files.
